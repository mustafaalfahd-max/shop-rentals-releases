# إصدارات تطبيق إيجاراتي

هذا المستودع يخدم التحديثات التلقائية لتطبيق **إيجاراتي** (إدارة إيجارات المحلات).

- `version.json` — بيان الإصدار الذي يقرأه التطبيق عند كل فتح.
- تبويب **Releases** — ملفات APK للتنزيل.

## التثبيت

نزّل أحدث APK من [صفحة الإصدارات](../../releases)، وثبّته فوق النسخة الحالية (بياناتك تبقى محفوظة).
